## 📌 Sobre o Projeto

O **Jogo do Número Secreto** é uma aplicação simples desenvolvida com foco educacional.  
O objetivo é permitir que o usuário tente adivinhar um número gerado aleatoriamente, recebendo feedback a cada tentativa.

Este projeto foi utilizado como prática em cursos de Lógica de Programação, reforçando conceitos como:

- Variáveis e tipos de dados  
- Estruturas condicionais  
- Funções  
- Manipulação do DOM  
- Interação com o usuário
